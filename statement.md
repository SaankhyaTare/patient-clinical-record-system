# Project Statement

### Project Title

### Patient Clinical Record Management System

### Problem Statement

Having to keep patient data by hand could cause trouble for a person to save, search and also manage records effectively.

This is an electronic computer-based system that allows storing patient information and medical records in a unique package.

It also features a clinical reference capability that compares inserted symptoms to predefined reference information.

### Scope

This project is about simple patient record management and reference of clinical.

### The system includes:

### - Adding patients

### - Viewing patients

### - Searching patients

### - Storing medical records

### - Viewing medical history

### - Clinical reference

### - Basic reports

### - Input validation

### - SQLite database storage

### Target Users

Primarily intended as an academic prototype for students, as well as a tool to demonstrate simple healthcare record management.

### High-Level Features

### 1. Patient Management

### 2. Medical Record Management

### 3. Clinical Reference

### 4. Report Generation

### 5. Input Validation

### 6. Database Storage

### 7. Automated Testing

### 8. Dashboard

### Project Limitation

Clinical reference features are only meant for study and information purposes. This does not provide medical diagnosis or prescriptions.
